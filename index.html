How the machine works

The machine

  • Memory: 16 cells, 8 bits each, with addresses 0 to 15 (4 bits). Instructions and data are stored in the same memory: this is the Von Neumann (stored-program) idea.
  • Instruction format: oooo aaaa. The first 4 bits are the op code (which instruction), the last 4 bits are the address X (which memory cell).
  • Registers: PC (program counter): address of the next instruction. IR (instruction register): the instruction being executed. MAR (memory address register): the address sent to memory. MDR (memory data register): the value fetched from or stored into memory. R: the register used by LOAD, STORE, ADD, SUBTRACT and COMPARE.
  • Condition codes GT, EQ, LT: set only by COMPARE, and used by the conditional jumps.
  • Numbers are whole numbers from 0 to 255 (8 bits). If a result does not fit (for example 200 + 100, or 3 − 5), only the last 8 bits are kept: this is called overflow.
  • content of X means "the number stored in memory cell X".

The instruction cycle

  1. Fetch: PC → MAR, content of cell MAR → MDR, MDR → IR, PC + 1 → PC
  2. Decode: the control unit reads the op code in IR.
  3. Execute: the steps listed in the table for that instruction.

Why are some registers 4 bits and others 8 bits?

PC and MAR hold addresses: there are 16 cells, and 4 bits are enough to count 0 to 15. MDR, IR and R hold whole memory cells (8 bits): a cell can be an instruction (op code + address) or a number up to 255. During fetch, MDR must carry the whole instruction to IR, op code included; only the address part (the last 4 bits) is later copied to MAR or PC.

Writing a program

.BEGIN                    -- first line of the program
AGAIN:  LOAD    ZERO      -- LABEL:  INSTRUCTION  X   -- comment
        COMPARE N         -- X can be a label or a cell number 0..15
        HALT
ZERO:   .DATA   0         -- a data cell holding 0
.END                      -- last line of the program
