How the machine works

The machine

  • Memory: 16 cells, 8 bits each, with addresses 0 to 15 (4 bits). Instructions and data are stored in the same memory: this is the Von Neumann (stored-program) idea.
  • Instruction format: oooo aaaa. The first 4 bits are the op code (which instruction), the last 4 bits are the address field X (which memory cell).
  • Registers: PC (program counter): address of the next instruction. IR (instruction register): the instruction being executed. MAR (memory address register): the address sent to memory. MDR (memory data register): the value fetched from or stored to memory. R: the register used by LOAD, STORE, ADD, SUBTRACT and COMPARE.
  • Condition codes GT, EQ, LT: set only by COMPARE, and used by the conditional jumps.
  • Numbers are 8-bit two's complement, from −128 to 127. A result outside this range wraps around (overflow).
  • CON(X) means "the contents of memory cell X".

The instruction cycle

  1. Fetch: PC → MAR, CON(MAR) → MDR, MDR → IR, PC + 1 → PC
  2. Decode: the instruction decoder reads the op code in IR.
  3. Execute: the steps listed in the table for that instruction.

Assembly language

.BEGIN                    -- first line of the program
AGAIN:  LOAD    ZERO      -- LABEL:  INSTRUCTION  X   -- comment
        COMPARE N         -- X can be a label or a cell number 0..15
        HALT
ZERO:   .DATA   0         -- a data cell holding 0
.END                      -- last line of the program
