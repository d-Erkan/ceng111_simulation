How the machine works

The machine

  • Memory: 32 cells, 8 bits each. Instructions and data live in the same memory: this is the Von Neumann (stored-program) idea. Any cell can be read as a number or as an instruction.
  • Instruction format: ooo aaaaa: 3-bit opcode, 5-bit address field.
  • Registers: PC (program counter: address of the next instruction), IR (instruction register: instruction being executed), MAR (memory address register: address sent to memory), MDR (memory data register: word read from / written to memory), AC (accumulator: operand and result of the ALU).
  • Flags: Z = 1 when AC is 0. N = 1 when the leftmost bit of AC is 1 (negative in two’s complement).
  • I/O is memory-mapped: reading cell 30 takes the next value from the Input box; writing cell 31 prints a value.
  • Arithmetic is 8-bit: results wrap around (250 + 10 = 4).

The instruction cycle

  1. Fetch: MAR ← PC; MDR ← M[MAR] and PC ← PC + 1; IR ← MDR
  2. Decode: the control unit splits IR into opcode and address field.
  3. Execute: the micro-operations listed below for that instruction.

Assembly syntax

label:  MNEMONIC operand   ; comment
loop:   LDA count          ; operand: label, number or label+1
        IN                 ; = LDA 30  (read input)
        OUT                ; = STA 31  (print AC)
count:  DATA 5, 0b101, -1  ; data cells
        ORG 20             ; continue placing at address 20

Binary format

001 00101        ; one 8-bit word per line, from address 0
00111: 00000101  ; optional "address:" prefix (5 binary digits or decimal)

Keyboard

S micro-step · I instruction · B back · R reset · Space run/pause
